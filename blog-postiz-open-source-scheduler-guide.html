What Is an Open Source Social Media Scheduler?

How to Self-Host Postiz with Docker (Step-by-Step)

Self-hosting Postiz takes about 15 minutes. You need a Linux server (or even a Raspberry Pi 4) with Docker installed. Here's the streamlined setup:

Step 1: Install Docker and Docker Compose

On Ubuntu/Debian:

Terminal sudo apt update && sudo apt install docker.io docker-compose -y sudo systemctl start docker

Step 2: Clone the Postiz Repository

Terminal git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app

Step 3: Configure Environment Variables

Copy the example environment file and configure your database and AI provider:

Terminal cp .env.example .env # Edit .env and set: # DATABASE_URL=postgres://user:password@localhost:5432/postiz # REDIS_URL=redis://localhost:6379 # AI_OPENAI_KEY=your-openai-api-key

Step 4: Launch with Docker Compose

Terminal docker-compose up -d

Postiz will start on http://your-server-ip:3000. The first time you visit, you'll set up your admin account and connect your social media channels via OAuth.

Step 5: Set Up a Reverse Proxy (Recommended)

For production, route traffic through Nginx or Cloudflare Tunnel for HTTPS and security:

Nginx Reverse Proxy (recommended) server { listen 80; server_name scheduler.yourdomain.com; location / { proxy_pass http://localhost:3000; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection 'upgrade'; proxy_set_header Host $host; proxy_cache_bypass $http_upgrade; } }
