How to Self-Host Postiz on Docker (Free)

One of Postiz biggest selling points is that you can run it on your own server for free. Here is what you need and how to get it running in under 30 minutes.

Prerequisites

  • A VPS with at least 2GB RAM (4GB recommended)
  • Docker and Docker Compose installed
  • A domain or subdomain pointed to your server

Installation Steps

Terminal — Docker Compose setup# Clone the Postiz repository git clone https://github.com/jackminchin/Postiz.git cd Postiz # Copy the environment file cp .env.example .env # Start all services docker-compose up -d # Check that everything is running docker-compose ps

The default .env file is pre-configured for a single-node setup with PostgreSQL and Redis included in the Compose stack. On first run, Docker creates the database volume automatically.

After starting, visit http://YOUR_SERVER_IP:3000 and complete the onboarding wizard to connect your first social accounts.

Production Hardening

For a public-facing deployment, you will want to add Traefik or Nginx Proxy Manager for automatic HTTPS, set up a proper .env with a strong SUPER_ADMIN_TOKEN, and configure PostgreSQL backups. The official Postiz Docker documentation covers production setup in detail.
