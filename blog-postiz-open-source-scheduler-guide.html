How to Self-Host Postiz on Docker (Free)

Self-hosting Postiz takes about 15 minutes on any VPS with Docker installed. Here's what you need:

  • A VPS with Ubuntu 20.04+ (~$6/month on Hetzner or DigitalOcean)
  • Domain name pointed to your server
  • PostgreSQL + Redis (Docker handles these)
  • Optional: OpenAI/Anthropic API key for AI captions
Docker Compose Setup (one-command deploy) # Clone Postiz git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app # Start with Docker Compose docker compose up -d # Postiz is now running at http://your-domain.com:3000

The official documentation at docs.postiz.com covers SSL setup, reverse proxy configuration with Nginx or Caddy, and environment variable tuning for production workloads.
