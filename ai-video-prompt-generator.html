Questions

Which video tools does this work with?

The output is plain text written for text-to-video models, so you can paste it into the tool you use.

Should I write one shot or a whole scene?

Start with one shot. Short, focused prompts tend to be easier to control, and you can run the generator once per shot.

Does it add sound?

It can include sound cues as a line in the prompt. Whether the video tool uses them depends on the tool.
