The Visual Calendar: How Queues Work

Postiz's core scheduling metaphor is the queue. You create content once, select which channels you want it to go to, and add it to a queue. From there, Postiz can publish immediately, schedule for a specific time, or use its AI-powered optimal timing feature to pick the best posting window based on your audience's activity patterns.

Queue Workflow in Postiz 1. Write/import content once 2. Select target channels (YouTube + TikTok + Instagram, for example) 3. Postiz auto-adapts format per platform (aspect ratio, caption length, hashtags) 4. Assign to queue → visual calendar shows all scheduled posts 5. Team members review and approve (if approval workflow is enabled) 6. Post publishes automatically at scheduled time

The visual calendar gives you a unified view of everything scheduled across all platforms — a major improvement over tabbing between Buffer, Later, and your other tools. You can drag-and-drop to reschedule, bulk-edit queue settings, and see at a glance which days are overloaded or sparse.

Self-Hosting: How It Works

If you're technically comfortable with Docker, self-hosting Postiz takes about 15 minutes. The official Docker Compose configuration handles the database, backend, and frontend containers with one command:

Postiz Docker Setup (5 Steps) # 1. Install Docker on your server (Ubuntu/Debian shown) curl -fsSL https://get.docker.com | sh # 2. Clone the Postiz repository git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app # 3. Copy environment configuration cp .env.example .env # Edit .env with your domain, database settings # 4. Start all services docker compose up -d # 5. Access Postiz at http://your-server-ip:3000

One-click deployment options exist for Railway, Render, and Proxmox for users who prefer not to manage Docker directly. The self-hosted version uses a local or external PostgreSQL database, Redis for caching, and can be exposed behind Nginx with Let's Encrypt for SSL.

When you self-host, you control where your data lives, you can integrate your own S3-compatible storage for media, and you own the entire stack. For European creators subject to GDPR or agencies with strict data residency requirements, this is not a trivial benefit.
