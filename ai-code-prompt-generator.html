Your rough idea

a function that checks if an email is valid

→
Enhanced prompt (example)
Task: write a function that validates an email address.
Language: JavaScript (ES2022), no external libraries.
Input: a single string. Output: a boolean.
Rules: require one @, a non-empty local part, and a domain with at least one dot; reject spaces.
Edge cases: empty string, leading or trailing spaces, multiple @ signs, very long input.
Style: small, readable function with comments only where the logic is not obvious.
Also provide: five test cases (three valid, two invalid) with expected results.

Questions

Which languages does it support?

You describe the language in your request, and the generator keeps it in the prompt. It is not limited to one language.

Does it write the code for me?

No. It writes a better prompt for you to give to a coding model. You paste the result into the tool you already use.

Can I add my own context?

Yes. Use Memory to keep notes about your stack, and edit the prompt before you copy it.
