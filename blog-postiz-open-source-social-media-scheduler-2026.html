What Is Postiz?

Postiz is an open source, agentic social media scheduling platform that lets you plan, write, schedule, and analyze content across 30+ social networks from a single visual calendar. It was created by gitroomhq and is available in two forms:

  • Cloud version – hosted by Postiz at postiz.com, starts at $15/month flat (unlimited channels, unlimited team members)
  • Self-hosted version – deploy on your own server via Docker, 100% free, same feature set as the cloud version

Unlike tools that monetize convenience, Postiz makes its core software completely free under the AGPL-3.0 license. You only pay for cloud hosting if you want Postiz to run it for you.

Key Features That Make Postiz Stand Out

1. Built-In AI for Caption and Content Generation

Postiz ships with a built-in AI agent that generates platform-tuned captions, hooks, threads, and hashtags — directly inside the app. No need to switch to ChatGPT, copy-paste, then reformat. The AI understands each platform's character limits, tone norms, and hashtag culture. You can also generate images and short videos inside Postiz itself.

For advanced users, Postiz's official dsh-postiz plugin lets you run DeepSeek as an agentic workflow engine — letting AI draft, revise, and queue posts with a human-in-the-loop approval step.

2. One-Click Docker Deployment (Self-Host Free)

If you have a server (even a $5/month VPS), you can run Postiz with a single Docker Compose file. There's no per-channel fee, no rate limiting on the self-hosted version, and no feature gates between free and paid.

Self-Host Postiz — Docker Compose git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app docker compose up -d # Postiz is now running at http://your-server:3000

The official Postiz GitHub repository has full instructions, and hosting platforms like Railway offer one-click deploy buttons.

3. 30+ Platform Integrations

Postiz connects to more platforms than almost any competitor:

  • Video: YouTube, TikTok, Instagram Reels, Facebook Video
  • Microblogging: X/Twitter, Bluesky, Mastodon, Threads
  • Professional: LinkedIn, Reddit, Pinterest, Google Business
  • DevOps: GitLab, GitHub
  • Community: Discord

All connections use official OAuth flows — Postiz never asks you to paste API keys into the hosted product, a privacy win over tools that require manual token management.

4. Visual Calendar and Queue Management

The visual calendar gives you a drag-and-drop overview of your entire content pipeline across all platforms. The queue view lets you set it-and-forget-it: Postiz pulls from your queue at optimal posting times and publishes automatically.

5. Team Collaboration Features

Postiz supports multiple users with role-based access, approval workflows, and shared workspaces — making it viable for small agencies and creator teams, not just solo operators.

6. n8n and Make.com Integration

Postiz exposes a well-documented public API. Combine it with n8n (free, self-hostable workflow automation) or Make.com to build custom pipelines: auto-post from RSS feeds, generate AI content on a schedule, or cross-post to multiple platforms with one trigger.
