How to Self-Host Postiz (Docker Setup in 15 Minutes)

One of Postiz's biggest advantages is that you can run it entirely on your own infrastructure. Here's what you need:

Requirements

  • A VPS or server with Ubuntu/Debian (2GB RAM minimum, 20GB storage)
  • Docker and Docker Compose installed
  • A domain or subdomain pointed to your server

Step 1 — Clone the Repository

Terminal 
git clone https://github.com/gitroomhq/postiz-app.git
cd postiz-app

Step 2 — Configure Environment

Terminal 
cp .env.example .env
nano .env  # Add your database password and domain

Step 3 — Start with Docker Compose

Terminal 
docker compose up -d

After a few minutes, open your browser to https://your-domain.com and you'll see the Postiz setup wizard. Create your admin account and start connecting channels.

AI-Powered Caption Generation: Write Better Posts Faster

One of Postiz's standout features is built-in AI assistance for caption writing. Instead of staring at a blank text box, Postiz can generate caption ideas, hashtag suggestions, and full post drafts based on your input.

Connect your own OpenAI, Anthropic, or any OpenAI-compatible API key, and Postiz uses it to:

  • Generate multiple caption variations to choose from
  • Suggest relevant hashtags based on your content
  • Rewrite existing posts for different platforms (a tweet → LinkedIn post)
  • Generate entire content calendars with a single prompt

This is genuinely useful for solo creators and small teams who struggle with consistency. Posting daily across 5+ platforms is sustainable when AI helps shoulder the writing load.
