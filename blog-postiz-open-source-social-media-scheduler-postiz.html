How to Self-Host Postiz in 10 Minutes

Postiz runs entirely in Docker, which means setup is straightforward even if you are not a DevOps engineer. Here is the fastest path:

Option 1: One-Click Deploy

Postiz supports one-click deployment on Railway, Render, and other platform-as-a-service providers. Connect your GitHub repo, configure your environment variables, and Postiz provisions itself. This is the recommended path if you want zero-hassle hosting.

Option 2: Docker on Your Own VPS

For maximum control and minimum cost, deploy on any Linux VPS:

Terminal # Install Docker if needed curl -fsSL https://get.docker.com | sh # Clone Postiz git clone https://github.com/gitroomhq/postiz.git cd postiz # Start all services docker-compose up -d # Open the web UI # Visit http://your-server-ip:3000

After the containers start, open your browser to port 3000, create your admin account, and connect your first social accounts. The entire stack — frontend, backend, database, and queue worker — spins up automatically via Docker Compose.

Environment Variables You Need

Postiz requires a few environment variables for email, AI providers, and media storage. The .env.example file in the repo documents every option. At minimum, you will want to configure:

  • DATABASE_URL — PostgreSQL connection string (handled by docker-compose)
  • NEXTAUTH_SECRET — random string for session encryption
  • AI_PROVIDER_API_KEY — OpenAI or Anthropic key for AI features
  • STORAGE_URL — S3-compatible storage or local filesystem path
