Postiz's Architecture for Agency Work

Setting Up Your Agency Workspace in Postiz

Here's the typical agency setup flow:

Step 1 — Create Client Workspaces

Each new client gets a dedicated workspace. Within that workspace, connect only their social channels. This keeps Instagram for Client A completely separate from Instagram for Client B.

Step 2 — Define Team Roles

Postiz supports role-based access control. Assign:

  • Admin: Agency owner — full access across all workspaces
  • Manager: Account manager for specific clients — can approve and publish
  • Drafter: Junior content creator — can create and submit for review only
  • Client: Via preview link — can view and comment without editing

Step 3 — Connect Channels via Official OAuth

Postiz uses official platform OAuth flows — no credential sharing. Connect each client's TikTok, Instagram, YouTube, Facebook, X, LinkedIn, Reddit, Pinterest, Google Business, and more directly from the platform's own authorization system. Postiz supports 32+ platforms via official API integrations.

The Client Approval Workflow (Built-In)

One of the most time-consuming parts of agency work is chasing clients for content approval. Postiz solves this with native workflow features:

  1. Draft — junior staff creates content in the Postiz composer
  2. Submit for Review — post is queued for manager approval
  3. Manager Review — account manager approves or requests changes
  4. Client Preview Link — share a direct link so the client can review without logging in
  5. Publish — approved content goes live on schedule across all connected channels

No more email chains with 14 versions of "can you approve this by Friday?" The entire approval trail is inside Postiz.
