Self-Hosting Postiz: Run It Free on Docker

Postiz is fully open source (AGPL). If you have a VPS or a home server, you can run Postiz at no software cost. The official Docker deployment takes under 10 minutes:

Docker Compose — Postiz Self-Host Setup # Clone the Postiz repository git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app # Start with Docker Compose docker compose up -d # Postiz is now running at http://your-server-ip:3000

The MCP Integration: Connecting External AI Agents to Postiz

Model Context Protocol (MCP) is the piece that makes Postiz genuinely agentic. MCP, pioneered by Anthropic and now an open standard, lets external AI systems interact with tools and data as if they were a user inside the application.

Postiz ships a hosted MCP server that you can connect to tools like:

  • Claude Code — instruct your AI coding assistant to post an update when you ship a feature
  • ChatGPT — generate and schedule a week's worth of content through a conversation
  • Custom agents — build internal automation that reads your Postiz analytics and adjusts posting schedules

Here's how a developer workflow looks in practice:

Postiz MCP — Triggering a Post from an External AI Agent # Connect Postiz MCP to your agent # The agent can now: # - list postiz integrations # - create a new post # - get analytics for your channels # - manage queue schedules # Example: Generate and schedule a product launch announcement /workspace $ postiz-agent create-post \ --platform youtube \ --content "We just shipped feature X. Here's how it works..." \ --schedule "2026-10-15T09:00:00Z"

This is the "AI agents using your tools" future that social media scheduling has been building toward. Instead of logging into a dashboard and manually queuing posts, you describe what you want to an AI agent and it handles the execution across your entire platform roster.

How to Schedule TikTok Posts with Postiz

TikTok scheduling is one of the most-requested features in social media tools — and one of the most inconsistently implemented. Postiz handles it properly through the official TikTok Content Posting API:

  1. Connect your TikTok account in Postiz under Settings → Integrations
  2. Upload your video file (MP4, up to 10 minutes)
  3. Let the AI agent draft your caption, hashtags, and cover image — or write your own
  4. Select a publish date and time
  5. Postiz posts directly to TikTok via the official API (not a draft-to-phone workaround)

Because Postiz uses TikTok's official API, your posts go live automatically — no phone, no notification, no manual intervention required at publish time.
