Why AI Forgets Everything When You Start a New Chat

Before the fixes, it helps to know why this happens at all. Modern AI language models process each conversation independently. The context window — the amount of text an AI can "see" at once — is fixed. When it fills up, older messages drop out. And when you close a chat and open a new one, there's no persistent connection between sessions.

Users describe this as "Groundhog Day pain" — the same conversation starting over and over. One Reddit user put it plainly: "Most AI setups die at session two. Nothing carried over."

The AI isn't being lazy. It's following its architecture. The solution is to inject your own persistent context layer — and there are several ways to do that depending on how deep you want to go.

Method 1: Custom Instructions — The Fastest Fix (Free, Takes 5 Minutes)

Custom Instructions is OpenAI's built-in feature that lets you tell ChatGPT who you are and how you want responses — permanently, across every chat.

To set it up: click your profile → Settings → Custom Instructions. There are two fields:

  • What would you like ChatGPT to know about you? — Your role, goals, preferences, ongoing projects.
  • How would you like ChatGPT to respond? — Tone, length, structure preferences.
Example Custom Instructions I run a small e-commerce business selling handmade candles. I need product descriptions that are warm, sensory, and conversion-focused — not generic adjectives. Keep responses under 150 words unless I ask for more. Always ask clarifying questions before writing marketing copy.

This persists across every chat session automatically. The AI reads your instructions first, before anything else, so you never have to re-establish who you are.

Other AI platforms have equivalents: Claude calls it "Instructions for Claude," Gemini calls it "Instructions for Gemini," and Copilot has its own version. All of them work on free tiers today.

Limitations of Custom Instructions

Custom Instructions is powerful but has a hard cap — roughly 1,500 characters (about a paragraph). That works fine for personal preferences, but it's nowhere near enough for project-specific context, a full product catalog, or detailed working documents. For that, you need a knowledge file.

Method 2: Knowledge Files — CLAUDE.md, chat-prompt.txt, and Project Context

Claude pioneered this approach: a plain-text file named CLAUDE.md that lives in your project folder. When Claude Code or Claude.ai sees that file, it reads it automatically and incorporates the context into every response.

CLAUDE.md example for a writing project # Project Context You are helping me write a series of blog posts about AI prompting for a Chrome extension called Prompt Helper Gemini. Our target audience is busy professionals who use AI tools but feel frustrated by generic outputs. # Tone and Style - Conversational, direct, no fluff - Use real customer phrases from forums, not marketing language - Aim for 1,500–2,000 words per post - Include concrete before/after prompt examples # Current Focus This week's post is about AI memory across conversations

ChatGPT doesn't auto-load .md files the same way, but the workaround is simple: open every new conversation by pasting a short opener that tells the AI to reference your context file. One line does it:

Prompt opener for new ChatGPT sessions Before you respond, read the context in my file "context.txt" and apply it to this conversation. [then paste your context or link to it]

You can maintain a single context.txt or about-me.md in a pinned browser tab, a notes app, or a shared folder — and paste that one-line opener at the start of every new conversation. It takes five seconds and completely eliminates the stranger problem.

Use cases where Custom GPTs shine:

The Session-Two Problem: Why Great First Sessions Go Downhill

Users consistently report that AI interactions feel magical in session one — context is fresh, the AI is aligned, outputs are excellent — and then deteriorate rapidly in session two and beyond. This isn't coincidence.

Session one: you provide rich, detailed context. The AI has everything it needs. Outputs are specific and high-quality.

Session two: you forgot to re-explain some of the context. Or you did re-explain, but subtly differently. The AI's responses drift. Outputs get more generic.

The solution is to make context injection a habit, not a hope. Treat every new chat as a continuation — open with your context file or Custom Instructions summary, then ask your question. That single habit eliminates the session-two cliff entirely.

When Context Window Is the Real Problem

Sometimes the issue isn't forgetting between sessions — it's forgetting within a session. Long threads (50+ messages) cause the context window to push older messages out, and the AI starts losing coherence. This is called context drift.

Signs you're experiencing context drift:

  • AI references something you discussed 30 messages ago that it seems to have "forgotten"
  • Outputs contradict something the AI agreed to earlier in the same conversation
  • You find yourself saying things like "remember, we agreed on X"

The fix is proactive context management:

  • Summarize mid-thread: Periodically ask the AI to summarize what's been established so far, and paste that summary back in when starting fresh
  • Restate key decisions: When the AI agrees to something important, note it explicitly and reference it when needed
  • Use structured formats: Frame ongoing work as a structured document (bullets, numbered lists) that the AI can re-read quickly

How do I make AI remember everything I tell it?

No AI remembers everything automatically. You control persistence through Custom Instructions, knowledge base files (CLAUDE.md, chat-prompt.txt), or a tool like Prompt Helper Gemini that enhances your prompts before every message to include the right context structure.

What is the best way to make AI remember context?

The most effective approach combines two methods: (1) set up Custom Instructions once in your AI settings, and (2) open every new conversation with a one-line prompt that loads your persistent context file. This two-layer system handles both personal preferences and project-specific memory.

Why does AI forget everything when I start a new chat?

AI models are stateless by design — each chat session starts with a fresh context window. Nothing carries over unless you explicitly inject it. This is a fundamental architecture decision, not a bug. The solution is to build your own memory layer using Custom Instructions, knowledge files, or a prompt enhancement tool.

Yes. Custom Instructions work on ChatGPT's free tier. OpenAI rolled them out to all users so you can set persistent preferences — your name, writing style, job role, how you want responses formatted — that apply to every new conversation automatically, without paying.

How does CLAUDE.md differ from ChatGPT Custom Instructions?

Custom Instructions has a ~1,500 character limit (about a paragraph). A CLAUDE.md file has no practical size limit — you can load full project briefs, style guides, and reference documents. Claude also respects CLAUDE.md automatically when you open a project folder, making it the more powerful option for complex, ongoing work.
