What Is the Postiz MCP Server?

The Postiz MCP server is a Model Context Protocol (MCP) implementation that bridges AI agents and the Postiz social media scheduler. MCP is an open standard that lets AI models call tools — think of it as a universal adapter between any AI agent and any service that exposes MCP tools.

With the Postiz MCP server loaded, an AI agent can:

  • List all connected social media channels
  • Upload images, videos, and other media files
  • Create and schedule posts across any combination of platforms
  • Retrieve scheduled and published post history

Postiz MCP Tools Reference

The server exposes a focused set of tools that cover the full scheduling lifecycle:

  • postiz-get-channels — Returns every connected social platform and account
  • postiz-upload — Uploads media (images, video, audio) and returns an upload reference
  • postiz-post — Creates a post on one or more channels, with scheduling options

These three tools are enough to run a complete AI-powered scheduling workflow. You can combine them in a loop to generate a week's content in one conversation with your AI agent.

Step-by-Step: Connecting Postiz MCP to Claude

The exact steps vary by client, but the pattern is consistent. Here is the Claude Desktop setup:

Step 1: Get the Postiz MCP Server URL

Log in to Postiz, navigate to Settings → Integrations, and copy the MCP server URL. It looks like https://mcp.postiz.com or your self-hosted equivalent.

Step 2: Configure Claude Desktop

Open Claude's configuration file and add a new MCP server entry:

Claude Desktop -- mcp.json snippet{ "mcpServers": { "postiz": { "command": "npx", "args": ["-y", "@postiz/mcp-server"] } } }

If you are self-hosting, replace the command with your own server URL in the npx command above or use a direct node invocation pointing to your hosted MCP endpoint.

Step 3: Authenticate

When Claude first calls a Postiz MCP tool, a browser window opens for OAuth authentication — the same flow you use to connect a social account to Postiz. Grant access and you are done. No API keys to copy, no secrets to store.

Step 4: Start Scheduling via Conversation

Once connected, simply talk to Claude:

Example prompt to ClaudeI want to post fitness tips every Monday, Wednesday, and Friday this week on Instagram, X, and LinkedIn. Write platform-specific captions for each post -- use a motivational tone. Upload the attached image to each post and schedule for 9am EST.

Claude will call the Postiz MCP tools in sequence: list your channels, upload the image, then create three scheduled posts across your chosen platforms.
