What Is Postiz?

How to Self-Host Postiz in 10 Minutes

Postiz runs on Docker, which means setup is straightforward even if you are not a DevOps expert. Here is the minimum setup:

Docker Compose (minimum configuration) # Clone the Postiz repository git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app # Start with Docker Compose docker-compose up -d # Postiz will be available at http://your-server-ip:3000

From there, you configure your OAuth connections for each platform — Postiz uses official social media APIs, never asks you to paste API keys into a third-party form. Connect your accounts, set up your posting calendar, and start queuing content.

The official Postiz documentation covers advanced configurations including custom domains, SMTP setup for email notifications, and reverse proxy configuration with Nginx or Caddy for SSL termination.
