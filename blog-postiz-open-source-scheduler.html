How to Self-Host Postiz on Docker

Self-hosting Postiz is straightforward if you have a Linux server with Docker installed. A $6/month VPS from Hetzner or DigitalOcean is more than enough for a personal or small-team setup.

Prerequisites

  • A Linux server (Ubuntu 20.04+ recommended)
  • Docker and Docker Compose installed
  • A domain or subdomain pointing to your server
  • At least 2GB RAM (4GB recommended)

One-Command Installation

Terminal — Docker Compose deployment git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app docker compose up -d

Postiz will start on port 4007 by default. After Docker pulls all services, open http://your-server-ip:4007 in your browser and complete the onboarding wizard.

Reverse Proxy Setup (Recommended)

For production use, put Nginx or Caddy in front of Postiz with SSL. This also lets you run it on a domain like scheduler.yoursite.com:

Nginx reverse proxy config server { listen 80; server_name scheduler.yoursite.com; location / { proxy_pass http://localhost:4007; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection 'upgrade'; proxy_set_header Host $host; proxy_cache_bypass $http_upgrade; } }

Postiz's official documentation at docs.postiz.com covers advanced deployment options including Temporal for workflow processing, Redis configuration, and production-grade hardening.
