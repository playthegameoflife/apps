Getting Started: Connecting Your First Platforms

Here is the process for connecting a new platform in Postiz:

  1. Navigate to Settings → Integrations in your Postiz dashboard
  2. Click Add Channel and select your platform from the list
  3. Authenticate via OAuth with your account credentials
  4. Postiz uses official platform-approved OAuth flows — no risky third-party logins
  5. Configure the channel name, default posting times, and approval workflow (for team accounts)
  6. Repeat for each platform you want to add

Platform Connection Time

  • Mainstream platforms (Facebook, Instagram, X): 2–3 minutes each via OAuth
  • Reddit: 3–5 minutes (requires Reddit app registration, Postiz guides you)
  • GitHub / GitLab: 2 minutes via personal access token
  • Bluesky / Mastodon: 5 minutes (AT Protocol authentication)
  • Google Business: 5–7 minutes (requires Google Cloud OAuth consent)
