How to Self-Host Postiz on Docker

Getting Postiz running on your own server takes under 20 minutes. You will need:

  • A VPS with at least 2GB RAM (4GB recommended)
  • Ubuntu 22.04 or Debian 12
  • A domain or subdomain pointing to your server IP
Terminal — Docker Compose Install# SSH into your VPS ssh root@your-server-ip # Install Docker curl -fsSL https://get.docker.com | sh # Clone Postiz git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app # Launch with Docker Compose docker compose up -d # Access Postiz at http://your-server-ip:3000

For a one-click Hostinger deployment, see Hostinger's Postiz VPS guide. Many hosts now offer Postiz as a one-click app, eliminating even the terminal step.
