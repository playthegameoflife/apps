Self-Hosting Postiz: Run It Free on Your Own Server

One of Postiz's biggest advantages is that you can self-host it on any server running Docker and Docker Compose. There is no vendor lock-in, no data harvesting, and no monthly fee beyond your server costs.

What You Need

  • A Linux server (Ubuntu 20.04+ recommended)
  • Docker and Docker Compose installed
  • A domain name or static IP pointing to your server
  • About 20 minutes and basic command-line comfort

Quick Setup (Docker Standalone)

Terminal # Clone the repository git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app/backend # Copy the environment file cp .env.example .env # Start all services (Postgres, Redis, Postiz) docker compose up -d # Access the app at http://your-server-ip:3000

The Docker setup automatically provisions PostgreSQL and Redis containers, so you don't need to manage a separate database server. For production, the docs recommend adding Traefik or nginx as a reverse proxy with HTTPS certificates via Let's Encrypt.

One-Command Alternatives

If the manual Docker setup feels involved, the community has packaged one-command installers. The softsweb/self-hosted-postiz project wraps everything in a single bash script with PostgreSQL, Redis, and automatic HTTPS via Traefik.

The Visual Calendar and Queue System

Postiz offers two primary scheduling paradigms: a visual calendar for planning content by date, and a queue system for drip-feeding posts at controlled intervals.

Visual Calendar

The calendar view shows every scheduled post across all connected channels. You can drag-and-drop posts to reschedule them, click any day to compose a new post, and filter by platform or workspace. This is the view most users spend the majority of their time in.

Queue System

The queue system is Postiz's most powerful scheduling mechanism. Instead of picking a specific date and time, you add posts to a queue and define an interval (post every X hours/minutes), a daily limit per channel, time windows (e.g., 9am–6pm only), and platform-specific pacing to avoid flooding TikTok with 10 posts in 5 minutes.

This is ideal for creators who batch-produce content on Sunday and want it distributed organically throughout the week — without manually spacing out each publish time.

AI-Assisted Content Generation

Postiz includes built-in AI features that most open source schedulers lack entirely:

  • AI caption writer: paste a topic or keywords, and Postiz generates platform-specific caption variations
  • Hashtag suggestions: AI recommends relevant hashtags based on your post content and target platform
  • Content recycling: AI can suggest when to repost existing high-performing content
  • Multi-platform adaptation: AI reformats a single long-form post into platform-native variations (LinkedIn article → Twitter thread → Instagram caption)

The AI features work via integration with LLM providers — you connect your own API key (OpenAI, Anthropic, or any OpenAI-compatible endpoint), so you're not locked into a specific AI vendor.

Team Workspaces and Permissions

Postiz's workspace model lets you isolate client accounts. A marketing agency can create separate workspaces per client, each with its own set of connected channels, calendar, and team members. Roles include Owner (full access), Admin (manage channels and team), Editor (create and schedule posts), and Viewer (read-only). Since there is no per-user pricing on the self-hosted plan, agencies can add unlimited team members at no additional cost.
