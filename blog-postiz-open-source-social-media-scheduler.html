What Is Postiz?

Postiz is an open-source social media management platform built for creators, marketers, and teams who want full control over their publishing workflow. It runs on a simple Docker deployment, giving you a self-hosted alternative to Buffer, Hootsuite, Later, and SocialBee — without per-seat licensing, platform lock-in, or monthly subscription tiers that scale faster than your following.

Postiz comes in two versions: a cloud-hosted service at postiz.pro with managed infrastructure, and a fully open-source self-hosted edition available on GitHub under the AGPL-3.0 license. Both versions share the same core feature set.

Self-Hosting with Docker — One Command

Deploying Postiz on your own infrastructure takes minutes. The official Docker Compose file gets you from zero to a fully functional scheduler in a single terminal command:

Self-host Postiz in one commandgit clone https://github.com/gitroomhq/postiz-app.git cd postiz-app docker compose up -d

Postiz runs on PostgreSQL for reliable data storage, uses Redis for job queuing, and persists everything in Docker volumes you control. Upgrade by pulling the latest image; backup by snapshotting the volume.

Calendar View and Queue Management

Postiz gives you a clean drag-and-drop calendar for visual scheduling, plus queue-based publishing that lets you set optimal posting windows per platform. Queue logic can be configured per-network, so your TikTok content drops when your audience is most active — automatically, without manual coordination.

Teams, Roles, and Approval Workflows

The Team plan ($39/month cloud, or self-hosted with your own auth layer) includes role-based access control and a content approval workflow. Small marketing teams can route posts through review before publishing — without paying for a Sprout Social-tier enterprise suite.

API, Webhooks, and MCP Server

Postiz exposes a full REST API and webhooks for custom integrations. The Pro and Ultimate plans add an MCP (Model Context Protocol) server for AI-native integrations — allowing AI agents and copilots to interact directly with your scheduling queue. For developers building automated workflows, this is a significant capability that most competitors don't offer even in enterprise tiers.

Analytics and Performance Tracking

Postiz tracks basic engagement metrics per post and per platform — likes, comments, shares, and reach — so you can measure what resonates without paying for a separate analytics dashboard. Deeper analytics integrations with platform-native tools are available through the API.
