How to Self-Host Postiz with Docker (Step-by-Step)

One of Postiz's strongest advantages is the ability to run it entirely on your own infrastructure. Here's how to get it running in under 10 minutes:

Prerequisites

  • A Linux server with Docker and Docker Compose installed
  • A domain or subdomain pointed to your server
  • At least 2GB RAM and 20GB disk space recommended

Step 1 — Clone the Repository

Terminal git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app

Step 2 — Configure Environment Variables

Terminal cp .env.example .env # Edit .env and set your database URL, JWT secret, and domain

Step 3 — Launch with Docker Compose

Terminal docker compose up -d

After startup, access Postiz at https://your-domain.com and complete the initial admin setup. The official Postiz documentation covers reverse proxy configuration (Nginx, Caddy), email setup, and custom domain SSL certificates in detail.

The self-hosted version includes all the same channel integrations and AI features as the cloud — you're simply paying for the server instead of a subscription.
