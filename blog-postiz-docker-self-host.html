How to Self-Host Postiz on Docker: A Step-by-Step Guide for 2026

Published October 6, 2026 · 10 min read · Self-Hosting · Social Media Tools

Commercial social media schedulers charge per channel, per seat, or both — and the bills add up fast once you manage more than a handful of accounts. Postiz changes that equation. As a fully open-source tool, it can be self-hosted on your own server for the cost of a cheap VPS — typically $5 to $20 per month. This guide walks through the complete self-hosting process, from choosing a server to getting your first post scheduled via your own Postiz instance.

Why Self-Host Postiz in 2026?

Postiz's cloud plan starts at $15/month for 5 channels — already competitive with commercial alternatives. But self-hosting removes even that cost and delivers additional benefits:

  • Unlimited channels and posts — no per-channel pricing
  • Full data ownership — your posts, analytics, and media stay on your infrastructure
  • No vendor lock-in — your data isn't trapped in someone else's SaaS
  • Custom domain and white-label for agencies and client work
  • Privacy-sensitive deployment — run behind a VPN if needed

For creators managing multiple brands, agencies handling client accounts, or anyone who resents paying escalating subscription fees, self-hosting Postiz is the most cost-effective path to professional-grade scheduling.

Server Requirements

Postiz runs as three Docker containers (frontend, backend, and queue). The resource demands are modest for small to medium setups:

Recommended Minimum

  • 2 GB RAM (4 GB preferred)
  • 2 vCPU cores
  • 20 GB storage (more for media-heavy use)
  • Ubuntu 22.04 LTS or Debian 12
  • Docker & Docker Compose installed

Good VPS Options

  • Hetzner Cloud (CX21: ~$6/mo)
  • DigitalOcean Basic ($6-12/mo)
  • Linode (2GB: $9/mo)
  • Contabo, Vultr, and Kimsufi all work

A $6-10/month VPS from Hetzner or DigitalOcean handles Postiz comfortably for most creators. If you're running analytics on large accounts or have a large team, bump up to 4 GB RAM.

Step 1: Set Up Your Server

Spin up a VPS with Ubuntu 22.04 LTS. Once SSH'd in, update the system and install Docker:

Terminal — Ubuntu setup sudo apt update && sudo apt upgrade -y curl -fsSL https://get.docker.com | sh sudo usermod -aG docker $USER docker --version docker compose version

Log out and back in for the Docker group permissions to take effect. Then verify:

Verify Docker docker run hello-world docker compose version

If both commands report success, your server is ready.

Step 2: Install Postiz

Clone the Postiz repository and start the Docker containers:

Terminal — clone and launch Postiz git clone https://github.com/gitroomhq/postiz-app.git cd postiz-app/docker cp .env.example .env docker compose up -d

The official Postiz Docker installation documentation covers the full environment configuration. Key variables you'll want to set in .env:

  • APP_URL — your domain (e.g., https://scheduler.yoursite.com)
  • FRONTEND_URL — the same URL for OAuth redirects
  • DATABASE_URL — set automatically by Docker, usually fine to leave

Step 3: Configure Domain and SSL

For OAuth authentication with TikTok, YouTube, Instagram, and other platforms to work, Postiz needs to run over HTTPS. Use a reverse proxy with free Let's Encrypt certificates.

Using Caddy (recommended — automatic HTTPS):

Caddyfile — reverse proxy with automatic SSL scheduler.yoursite.com { reverse_proxy localhost:3000 }

Run caddy run and Caddy automatically provisions and renews your SSL certificate. If you prefer Nginx, use Certbot with certbot --nginx to generate certificates.

Point your domain's DNS A record at your server's IP address before starting the proxy — DNS propagation can take up to 24 hours, though it often completes in minutes to a few hours.

Step 4: Connect Your Social Platforms

Navigate to your Postiz instance at your domain. Create your admin account, then add channels from the dashboard:

  • Click Channels → Add Channel
  • Select your platform (YouTube, TikTok, Instagram, Facebook, etc.)
  • Authenticate via the official OAuth flow — Postiz uses platform-approved methods and never asks for your passwords
  • Repeat for each account you want to manage

Because Postiz uses official OAuth, it won't get your accounts banned or restricted the way tools based on scraping or unofficial APIs can.

Step 5: Using Queues and Scheduling

Postiz uses a queue-based system (backed by Temporal since v2.12) to handle scheduling reliably. To schedule a post:

  1. Click Create Post in the dashboard
  2. Select which channels to publish to
  3. Write your caption, attach media, add hashtags
  4. Choose Publish Now or pick a future date and time
  5. Add to queue — Postiz handles delivery at the scheduled moment

The queue system means posts go out even if your computer is off. Postiz's worker process runs on your server, checking the queue and publishing at the right time across all connected platforms.

Bonus: Using Postiz's AI Smart Agent

Postiz includes a built-in AI agent that can generate your captions, images, and short videos from a single idea. To use it:

  1. Click AI Agent in the dashboard
  2. Enter a topic or concept for your campaign
  3. The AI generates platform-native captions, suggested images, hashtag sets, and video concepts for each channel
  4. Review, edit, and approve before queuing

The AI agent is included on Postiz's paid cloud plans. For self-hosted, configure your own AI provider via the environment variables, or use the built-in integration options available in the dashboard settings.

Frequently Asked Questions

What are the minimum server requirements for self-hosting Postiz?

Postiz recommends at least 2 GB of RAM, a dual-core CPU, and 20 GB of storage. A cheap VPS (like a $5-10/month instance from DigitalOcean, Hetzner, or Linode) handles a small to medium setup comfortably. The official Docker compose uses three containers, so resource availability matters.

Is Postiz really free to self-host?

Yes. Postiz is fully open source under the MIT license. Self-hosting it costs only your server expenses, typically $5-20/month depending on your VPS provider. There are no Postiz licensing fees, no account limits, and no feature restrictions — everything is included.

How do I update Postiz when self-hosted?

Update Postiz by pulling the latest Docker images and restarting the containers: git pull, docker compose pull, docker compose down, docker compose up -d. Postiz maintains backward compatibility in updates, and your data is stored in Docker volumes, so it persists across updates.

Can I use a domain with my self-hosted Postiz?

Yes. You can configure a custom domain with SSL via a reverse proxy like Nginx or Caddy. Postiz's Docker compose includes environment variables for setting your domain. Using a domain with HTTPS is essential for OAuth authentication with platforms like TikTok, YouTube, and Instagram.

What happens to my data if Postiz shuts down?

Because you host Postiz yourself, you own your data completely. If the project were ever discontinued, you'd still have your database, scheduled posts, and media files on your server. You could switch to another tool without losing anything — unlike SaaS platforms where cancellation means data loss.
